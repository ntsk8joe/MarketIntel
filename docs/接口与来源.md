# 接口与来源

## 本地 API

只监听本机。POST 需使用 `/api/state` 返回的 `csrf` 值作为 `X-MarketIntel-Token`，校验 Host 和浏览器 Origin；不提供跨域访问。

| 接口 | 方法与正文 | 返回 |
|---|---|---|
| `/api/state` | GET | 档案、评估、任务、变化、快照元数据、连接配置状态 |
| `/api/connections` | POST `{values:{APIFY_TOKEN?:string,...}}` | 保存本机连接；返回配置状态与模型 ID，不返回凭据 |
| `/api/records` | POST `{kind,name,project_id,data,id?}` | 保存记录；同 ID 更新、同步笔记 |
| `/api/search?q=...&project=...` | GET | 本地 Markdown 命中与摘录；project 可省略 |
| `/api/note?path=...` | GET | vault 内 Markdown 正文 |
| `/api/collect` | POST `{source_id,resume_id?,confirmed_new?:boolean}` | 后台采集 job_id；未取得远端 ID 的 Apify 任务禁止恢复，核查后新建需显式 confirmed_new=true |
| `/api/snapshot?id=...` | GET | 历史快照正文 |
| `/api/changes/review` | POST `{id}` | 标记变化已阅 |
| `/api/discover` | POST `{project_id,query,provider}` | provider 为 hackernews 或 github；待审核线索和历史命中 |
| `/api/import` | POST `{project_id,rows}` 或 `{project_id,format:"csv",text}` | 校验后导入待审核证据并去重 |
| `/api/keywords` | POST `{project_id,keywords}` | 可选付费关键词查询结果记录 ID |
| `/api/ai` | POST `{project_id,question}` | 可选模型摘要记录 ID |
| `/api/sync` | POST `{}` | 知识库同步/冲突数 |
| `/api/backup` | POST `{}` | 本地备份位置 |
| `/api/export?type=...` | GET | json / csv / markdown；CSV 与报告支持 project 过滤 |

source 支持 type、url、interval_hours（1—87600 小时）、tracking、capture_allowed、save_raw；布尔字段仅接受 true/false。Apify 另含 actor_id、actor_input、max_charge、allow_apify。其他实体字段可在工作台查看，所有记录数据保存为标准 JSON，拒绝 NaN/Infinity。带凭据的供应商请求禁止跟随重定向。

JSON 导出不受界面 200 条快照/变化记录限制；仍仅导出快照元数据与预览。检索要求每个关键词均匹配，跳过非 UTF-8 或超过 100 万字符的 Markdown。证据关联 ID 自动去重并校验所属方向；快照证据保留 source_id 与 snapshot_id。

## 官方数据源与依赖依据

- [Hacker News 搜索 API / Algolia 开源说明](https://github.com/algolia/hn-search)：按关键词取得最多 30 条讨论，保存原帖 URL 和同帖分组。
- [GitHub REST Search 文档](https://docs.github.com/en/rest/search/search)：公开 issue 线索；返回关闭状态也不自动等于商业问题已解决。
- [Apify 启动 Actor 文档](https://docs.apify.com/api/v2/actors-runs-post)：启动、超时及费用上限参数。
- [Apify 获取运行状态](https://docs.apify.com/api/v2/actor-run-get)：保存远端 run ID 后恢复查询。
- [DataForSEO Google Ads Search Volume Live](https://docs.dataforseo.com/v3/keywords_data-google_ads-search_volume-live/)：按美国英文口径返回指标与成本。
- [OpenRouter API](https://openrouter.ai/docs/api_reference/overview)：可选模型研判接口。
- [Obsidian 本地知识库说明](https://help.obsidian.md/vault)：Markdown 目录可独立打开。
- [SQLite 在线备份 API](https://www.sqlite.org/backup.html)：在持锁期间建立数据库备份。

公开讨论平台不会覆盖全部买单人。这个版本不安装陌生 GitHub skill，不把“开源”“点赞数”当成安全性或需求证明。已有开源 API 说明帮助实现采集；后续若使用外部 skill，需要另外审查内容、许可与执行权限。

默认新建空库；通过 --demo 可选载入历史演示数据，其来源 URL、日期与待审核状态保存在档案内。程序不会读取父目录或自动复制个人报告。
