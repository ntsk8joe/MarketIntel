# 安全与功能回归报告

检查日期：2026-09-27。对象：MarketIntel 本机单用户版本。

本次检查以代码审查、恶意输入测试、模拟供应商响应、临时数据库和真实浏览器操作为依据。先记录失败用例，再修改代码并运行回归。测试没有调用真实付费账号，没有将测试证据、收款或决策写入使用者的研究库。

## 结论与使用范围

已修复下表中复现的问题，补上长期历史导出和收费重试核查流程。当前用途仍是可信电脑上的个人研究工作台；Host/Origin/token 防护不等于登录认证，不适合直接作为公网、多用户 SaaS。

密钥由每个使用者自行配置，仍以明文保存在独立本机配置文件中。文件权限、脱敏、禁止重定向和发布包排除降低了泄露风险，但不能防御已控制本机账号的攻击者。这份报告不是独立渗透测试证书，也不作“百分之百安全”的保证。

## 已复现并修复

优先级表示修复顺序及对当前工作流的影响，不是未经测量的 CVSS 分数。

| 优先级 | 问题及成立条件 | 修复与验证依据 |
|---|---|---|
| P1 | 带 Authorization 的供应商请求可能跟随重定向，将头发送到另一地址；需要供应商响应重定向 | 三个供应商共用禁止重定向的 JSON 请求函数；本机两个模拟服务验证目标地址未收到请求 |
| P1 | Apify 请求进行中轮换密钥，异常若包含旧密钥，会用新密钥脱敏而遗漏旧值 | 使用实际发出请求时的密钥脱敏；模拟轮换后检查任务、来源及导出没有旧密钥 |
| P1 | 未取得 Apify run ID 的失败任务，恢复可能启动另一次收费任务 | 禁止无 ID 恢复；重新启动须核查后明确确认；模拟断网验证没有创建线程或再次请求 |
| P1 | 预置笔记临时文件、冲突文件或 raw 目录的符号链接，可使写入越出预期目录；需要先能修改本地文件 | 边界/符号链接检查与随机临时文件原子替换；验证外部文件仍为原值、外部目录没有新文件 |
| P1 | 不可信证据中的公式开头进入 CSV；打开表格时可能被解释为公式 | 公式开头加文字前缀、字段全引用及引号转义；测试 ASCII、制表符、回车、空白、BOM 与全角开头。未在表格软件中验证执行行为 |
| P2 | 恢复只从最近 100 条任务列表找 ID，早期任务无法恢复 | 增加按任务 ID 查库；测试超过 100 条后仍使用原 run ID |
| P2 | JSON 导出误用了界面的 200 条上限，长期快照和变化元数据遗漏 | 导出与界面上限分开；各 205 条构造记录验证全部导出，界面仍显示最近 200 条 |
| P2 | 空列表、布尔值等被转换为空对象；NaN 可以进入 JSON；错误字段类型可影响界面或自动追踪 | 保存前检查对象类型、标准 JSON、文本及布尔字段；非法请求返回 400 |
| P2 | 极大复核间隔会抛 OverflowError；经济情景计算可得到无穷大 | 复核间隔限 1—87600 小时，旧异常间隔不自动采集；拒绝计算溢出 |
| P2 | 同一证据 ID 重复关联会放大已审核数量；竞品可以引用另一方向的证据 | 关联 ID 去重、校验所属方向；历史评估同样去重和过滤 |
| P2 | 一份损坏的人工 Markdown 会令整个搜索失败 | 跳过不可读取、非 UTF-8、超过 100 万字符或越界的笔记；其余命中正常返回 |
| P2 | 多词查询匹配任意词，无关笔记的高频单词可能把相关结果挤到后面 | 每个关键词必须匹配；相关与无关笔记对照测试 |
| P2 | 从快照建立新证据时隐藏的 source_id/snapshot_id 被丢弃 | 编辑器保留预填元数据；浏览器保存后查 API 验证两项来源关联仍存在 |
| P2 | 慢检索响应覆盖更新的关键词结果 | 查询版本检查；模拟先发后到响应，最终仍显示最新查询 |

额外加固：连接 15 秒无活动超时、拒绝重复 Content-Length 和分块正文、日志不记录查询参数、GET 异常脱敏、补充 CSP 和 Referrer-Policy、POSIX 数据访问权限、导入去重持锁。以上是防护改动，不将未做专门攻击验证的内容称为已复现漏洞。

## 适合后续完善的功能

| 顺序 | 功能 | 需要解决的问题 | 本次状态 |
|---|---|---|---|
| 1 | 备份校验与恢复向导、数据库版本迁移 | 当前恢复需要停止程序后手动复制，长期升级容易操作错误 | 保留人工恢复说明，未扩展数据库结构 |
| 2 | 任务/快照分页及时间范围查询 | 工作台仍只显示最近 100 条任务、200 条快照和变化；历史数据不会因此删除 | 本次先修复完整元数据导出和按 ID 恢复 |
| 3 | 每日费用台账、请求幂等及人工核对 | 供应商不一定支持统一幂等键；断网后费用需要到供应商核对 | 本次实现 Apify 不确定启动保护；未保证所有付费请求都能做到恰好一次 |
| 4 | 系统钥匙串支持 | 当前连接文件有访问权限限制，但没有加密 | 本次保持 BYOK 与不回显，未引入新的系统依赖 |
| 5 | 来源到期与证据过期队列、核查记录 | 有来源变化不等于结论变化，需要追踪何时重新审核某条证据 | 现有到期检查和人工变化审核保留 |

这些是后续规划，不是已经实现的功能。优先让证据来源、核查时间、历史版本和实际验证记录保持一致；不以采集数量推断需求、利润或成功率。

## 未验证部分

未使用真实 Apify、DataForSEO、OpenRouter 账号做付费调用；未在 Windows 或 Excel/LibreOffice 上实际执行；未做公网、多用户、完整拒绝服务或第三方独立渗透测试。采集和 HTTP 超时主要是单次无活动限制，不能当作全部流程的总耗时保证。第三方来源政策和 API 变动仍需维护。

CSV 防护及其跨软件限制参考 [OWASP CSV Injection](https://community.owasp.org/attacks/CSV_Injection)；禁止重定向使用 Python 官方的 [HTTPRedirectHandler](https://docs.python.org/3/library/urllib.request.html#urllib.request.HTTPRedirectHandler) 扩展机制。具体修复结果来自本仓库测试，而非引用文档所作的保证。
